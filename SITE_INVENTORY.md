## 공통 화면과 인터랙션

- EN/KR 버튼, URL lang 쿼리와 localStorage 언어 기억, 키보드 접근성, 모바일 메뉴·Escape 닫기.
- Canvas 금융 네트워크 지구본과 움직임 일시정지, 스크롤 등장 효과.
- capability·결제 DvP/PvP·장부 보기·네트워크 노드·자산 생명주기·정책 예시 선택, details 펼치기. 금융 기능은 가상 설명 UI다.
- 문의는 공개 이메일과 복사 버튼. 메인 공개 번들에는 실제 거래 API 호출을 발견하지 못했다.
- SEO: 페이지별 제목·description, canonical, OG/Twitter, JSON-LD, sitemap·robots·favicon. 원본 운영 도메인 canonical을 보존했다.
- CSS: DM Sans, IBM Plex Mono, Noto Sans KR Google Fonts 요청. 이미지 로고 1개와 favicon SVG, 코드 내 SVG 및 Canvas. 메인 페이지에서 동영상·공개 PDF·JSON 다운로드는 발견하지 못했다.
